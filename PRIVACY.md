# Privacidad

## Datos recopilados por YTMusicLite

YTMusicLite no incluye analítica, telemetría, publicidad propia ni servidores de seguimiento. El código de la aplicación no envía información a sus autores.

## Datos del navegador integrado

La aplicación utiliza Microsoft Edge WebView2 para abrir `https://music.youtube.com/`. WebView2 almacena localmente cookies, caché y otros datos de navegación en:

```text
%LOCALAPPDATA%\YTMusicLite\WebView2
```

Estos datos pueden incluir una sesión iniciada en Google. No deben adjuntarse a issues ni compartirse con terceros.

Para borrar los datos locales, cierra YTMusicLite y elimina esa carpeta. La próxima ejecución comenzará con un perfil nuevo.

## Servicios externos

El uso de YouTube Music está sujeto a las políticas de privacidad y condiciones de Google y YouTube. YTMusicLite no controla las solicitudes, cookies ni datos procesados por esos servicios.
