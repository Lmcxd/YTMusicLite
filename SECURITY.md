# Seguridad

## Versiones compatibles

Mientras el proyecto permanezca en la serie `0.1.x`, solo la versión más reciente recibirá correcciones.

## Informar una vulnerabilidad

No publiques vulnerabilidades, cookies, tokens ni datos del perfil WebView2 en un issue público.

Cuando el repositorio esté publicado, utiliza **Security > Report a vulnerability** en GitHub. Si esa opción todavía no está disponible, abre un issue sin detalles sensibles para solicitar un canal privado de contacto.

Incluye una descripción del impacto, pasos mínimos para reproducirlo y la versión afectada. No adjuntes el contenido de `%LOCALAPPDATA%\YTMusicLite\WebView2`.
